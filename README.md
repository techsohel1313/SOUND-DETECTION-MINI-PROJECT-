# SOUND-DETECTION-MINI-PROJECT-
Project Title: Sound Detection – Turn ON LED & Buzzer

This is a simple electronics mini project that detects sound using a sound detection sensor. When the sensor detects a sound such as clapping, speaking, loud noise, or tapping, it sends a signal to activate an LED and buzzer.

The main purpose of this project is to understand how sound sensors work and how electronic components respond to sound signals.

Components Used

Sound Detection Sensor

LED

Buzzer

Breadboard

1K Ohm Resistor

Jumper Wires

9V Battery

Working Principle

The sound sensor detects sound.

The sensor converts sound into an electrical signal.

The signal activates the LED and buzzer.

The LED glows and the buzzer produces sound.

Applications

Sound detection systems

Noise alert systems

Basic security systems

Electronics learning projects

Conclusion: This project demonstrates how sound can be detected and used to control electronic components like an LED and buzzer.
